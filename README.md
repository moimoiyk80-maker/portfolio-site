# UI/UX Portfolio

UI/UX 디자인, 반응형 퍼블리싱과 디자인 시스템 경험을
세 개의 프로젝트를 통해 정리한 개인 포트폴리오 사이트입니다.

## Project Links

## Portfolio Overview

이 포트폴리오는 프로젝트 결과물을 단순히 나열하기보다,
UI 설계와 구현 환경에 대한 이해가 단계적으로 확장되는 흐름으로 구성했습니다.

```text
Minimal Ecommerce
상품 탐색과 반응형 인터랙션
        ↓
Frame Design System
토큰과 컴포넌트 기준 체계화
        ↓
SLI Scientific
B2B 정보구조와 제품 탐색 경험에 적용
```
사이트에서는 채용 관점에서 핵심 역량이 가장 잘 드러나는 순서로
SLI Scientific, Frame Design System과 Minimal Ecommerce를 소개합니다.

각 프로젝트의 문제 정의, 설계 방향, 역할과 결과를
프로젝트 상세 페이지에서 확인할 수 있도록 구성했습니다.

## Featured Projects

### 1. SLI Scientific

회사소개와 홍보 콘텐츠 중심의 B2B 사이트를
제품 탐색, 상세 검토, 자료 확인과 문의가 이어지는
제품 중심 정보 플랫폼으로 재구성한 프로젝트입니다.

주요 내용:

- 제품 중심 정보구조와 사용자 흐름
- 검색과 카테고리를 활용한 제품 탐색
- 모델, 주요 기능과 기술 사양을 단계적으로 보여주는 상세 구조
- 검토한 제품 정보가 이어지는 문의 경험
- Frame Design System 원칙의 서비스 맥락 적용
- Desktop, Tablet과 Mobile 반응형 UI

- [Live Site](https://platform-redesign-five.vercel.app/)
- [GitHub Repository](https://github.com/moimoiyk80-maker/platform-redesign)

### 2. Frame Design System

색상, 타이포그래피, 간격과 상태 기준을
디자인 토큰과 컴포넌트 원칙으로 체계화한
디자인 시스템 포트폴리오 프로젝트입니다.

주요 내용:

- Primitive, Semantic과 Component Token 구조
- 공통 UI의 크기, 변형과 상태 기준
- Light/Dark Theme
- 컴포넌트 사용 원칙과 문서화
- Figma 기준과 브라우저 UI의 연결
- SLI Scientific 프로젝트로의 확장 적용

- [Live Site](https://frame-design-system.vercel.app/)
- [GitHub Repository](https://github.com/moimoiyk80-maker/frame-design-system)

### 3. Minimal Ecommerce

상품 검색과 필터, 상세 옵션 선택, 관심 상품과 장바구니가
하나의 흐름으로 이어지도록 구성한 반응형 커머스 UI 프로젝트입니다.

주요 내용:

- 검색, 필터와 정렬을 활용한 상품 탐색
- 상품 상세 옵션과 수량 선택
- 관심 상품, 최근 본 상품과 장바구니 흐름
- 선택 결과가 명확하게 드러나는 상태별 UI
- 모바일 환경에 맞춘 필터와 정렬 방식
- 다양한 화면 크기에 대응하는 반응형 UI

- [Live Site](https://minimal-ecommerce-psi.vercel.app/)
- [GitHub Repository](https://github.com/moimoiyk80-maker/minimal-ecommerce)

## My Role

프로젝트를 진행하며 다음 영역을 중심으로 작업했습니다.

- 프로젝트 목적과 핵심 문제 정의
- 정보구조와 사용자 흐름 설계
- 주요 화면의 UI/UX 디자인
- 디자인 토큰과 컴포넌트 기준 정리
- 콘텐츠 구조와 프로젝트 설명 작성
- Desktop, Tablet과 Mobile 반응형 기준 정의
- HTML/CSS 퍼블리싱과 화면 조정
- 브라우저에서 인터랙션과 반응형 결과를 확인하고 UI 조정
- 이미지와 콘텐츠 에셋 관리
- GitHub 저장소 관리 및 Vercel 배포

## Portfolio Structure

포트폴리오 사이트는 주요 역량과 프로젝트를
빠르게 파악할 수 있도록 다음 구조로 구성했습니다.

```text
Home
├─ Hero
├─ Selected Projects
├─ About
├─ Capabilities
└─ Contact

Project Detail
├─ Project Overview
├─ Challenge
├─ Approach
├─ My Role
├─ Key Screens
├─ Outcome
└─ Project Links
```
홈에서는 핵심 포지셔닝과 프로젝트 전체를 먼저 확인할 수 있도록 하고,
상세 페이지에서는 각 프로젝트의 문제, 설계 과정과 결과를
순서대로 살펴볼 수 있도록 구성했습니다.

### Project Navigation

프로젝트는 채용 관점에서 핵심 역량이 잘 드러나는 순서로 배치했습니다.

```text
SLI Scientific
        ↓
Frame Design System
        ↓
Minimal Ecommerce
```
각 프로젝트 상세 페이지에서는
Live Site와 GitHub 저장소를 확인할 수 있도록 구성했습니다.

### Responsive Design

데스크톱 화면을 단순히 축소하지 않고,
화면 크기에 따라 콘텐츠 배열과 탐색 방식을 조정했습니다.

Desktop: 프로젝트 설명과 이미지를 넓은 화면에서 함께 확인
Tablet: 콘텐츠 폭과 프로젝트 카드 배열 조정
Mobile: 주요 메시지와 프로젝트 정보를 세로 흐름으로 재구성

헤더 내비게이션, 프로젝트 카드와 상세 페이지 콘텐츠가
작은 화면에서도 화면 밖으로 벗어나지 않고
자연스러운 순서로 이어지도록 조정했습니다.
